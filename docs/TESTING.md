# 测试说明

## 命令

```bash
npm test
npm run build
```

## 自动化覆盖

- 导航主要链接、主题切换按钮与移动菜单。
- 四类页面、实践详情和学习内容详情路由。
- Hero 在无 WebGL 依赖时保留标题、CTA、用户头像和静态视觉回退。
- AI 入口覆盖英文 `AI ASSISTANT` 预留按钮的显示。
- Dify 适配器覆盖正常加载、缺少 token 和重复加载三种路径。
- Project Deck 覆盖项目切换、详情内容更新和详情路由关联。
- How I Work 手风琴覆盖默认展开与重复点击收起。
- WonderExperience 覆盖开场场景、第二场景标题和主题卡片数据渲染。

## 手动验收

- 桌面与移动端无横向溢出。
- 首页 60 秒阅读结构完整且无空白内容块。
- 亮暗主题选择可以保存。
- 键盘可操作导航、主题按钮和布局切换器。
- reduced-motion 下内容直接显示，非必要动画停止。
- 桌面端项目 deck 可通过鼠标或触摸选择卡片，移动端不横向溢出。
- `AI ASSISTANT` 预留入口可由键盘操作；原始 Dify 气泡隐藏，桌面和移动端均不溢出视口。
- `/about` 进入后先显示 Wonder 开场，向下滚动可看到第二场景与弧线卡片；Projects、Writing 及详情页保持暖色设计上下文且内容可读。
